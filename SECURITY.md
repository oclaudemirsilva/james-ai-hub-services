# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the JAMES AI Assistant
project, please report it **privately** rather than opening a public
issue.

**Email:** claudemircloud@gmail.com

Please include:

- A description of the issue
- Steps to reproduce
- Affected version or commit hash, if known
- An impact assessment, if available

You will receive an acknowledgement within 7 days and a status update
within 14 days.

## Supported Versions

Only the latest commit on `main` of the JAMES source repository is
actively maintained. Older commits do not receive security patches.

## Disclosure Policy

Responsible disclosure is appreciated. Please allow a reasonable window
(30 days by default) for a fix to be developed and deployed before
public disclosure, except in cases of active exploitation, where a
shorter window may be appropriate.

## Scope

This policy covers:

- The JAMES AI Assistant project source code
- The policy documents hosted in this repository

It does **not** cover:

- Third-party services that JAMES integrates with (report those to the
  respective vendors — Google, TikTok, Meta, Spotify, Anthropic, etc.)
- Forks of JAMES maintained by third parties
