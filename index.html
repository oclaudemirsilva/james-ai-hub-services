What this is

This site hosts the public-facing policy documents and service contracts that govern how the JAMES AI Assistant interacts with external services (TikTok, Meta, Google, Spotify, and others).

The JAMES source code lives in a separate repository and is not part of this site. This site holds policy text only and has no runtime role.
