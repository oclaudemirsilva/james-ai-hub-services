# Contributing to james-ai-hub-services

Thanks for your interest in helping. This repository holds the
public-facing policy and service-contract documents for the JAMES AI
Assistant project. It is **not** the JAMES source code (that lives in a
separate repository).

## What contributions are welcome here

- Corrections to factual errors in policy docs (TERMS, PRIVACY,
  DATA_DELETION, SECURITY)
- Typo, grammar, or clarity improvements
- Translations of policy docs to other languages
- Suggested additions of per-service documentation when a new
  third-party integration is added to JAMES

## What is NOT in scope

- JAMES source code — that lives in a separate repository
- Plugin or integration code — not handled here
- User support questions — open an issue at the main JAMES repository
  instead

## How to contribute

1. **Fork** this repository
2. Create a **topic branch** with a clear name
   (e.g. `fix/typo-in-privacy`, `add/spotify-service-doc`)
3. Make your change with a **clear commit message** explaining the why,
   not just the what
4. Open a **Pull Request** describing what changed and why
5. Wait for review — response time goal: within 7 days

## Style guidelines

- Markdown is the only format used in this repo
- One sentence per line is fine; flowing paragraphs are also fine —
  match the surrounding text
- Match the existing tone: factual, plain English, no marketing copy
- For changes to legal/policy text, explain the legal or compliance
  reasoning in the PR description so the reviewer can evaluate context
